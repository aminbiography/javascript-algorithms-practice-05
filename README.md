## Introduction

This resource introduces **JavaScript DOM Events and Event Handlers**, demonstrating how to respond to user interactions and dynamically update webpage content. It combines HTML examples with JavaScript event-handling techniques to explain how events work in the browser.

The examples focus on handling button clicks, changing background colors, updating text, reading input values, displaying comments, and implementing a delete confirmation interaction.

## Topics Covered

### 1. Introduction to DOM Events
- What events are in web development
- Different types of web events
- Event handlers and their purpose

### 2. Methods of Handling Events
- Using inline `onclick` attributes
- Calling JavaScript functions from HTML
- Assigning event handlers through JavaScript
- Using the `onclick` property
- Using `addEventListener()`
- Registering named functions and anonymous callback functions

### 3. Working with DOM Elements
- Selecting elements using `document.getElementById()`
- Updating webpage content with `innerText`
- Changing CSS styles through JavaScript
- Updating the background color dynamically

### 4. Handling Input Events
- Reading input field values
- Updating displayed text from user input
- Clearing input fields after submission
- Handling `focus`, `blur`, `mousemove`, `keydown`, `keypress`, and `keyup` events
- Accessing input values through `event.target.value`

### 5. Practical DOM Event Projects
- Creating a comment box and displaying submitted comments
- Dynamically creating HTML elements with `document.createElement()`
- Adding elements using `appendChild()`
- Hiding webpage content through a delete button
- Building a GitHub-style delete confirmation interaction

### 6. Advanced DOM Event Concepts
- Event bubbling
- Stopping event propagation
- Event delegation and its benefits

### 7. DOM Events Summary and Practice
- Reviewing common event-handler techniques
- Changing background colors with event handlers
- Handling keyboard events on an email input field
- Practicing DOM event interactions

## Learning Approach

The materials use practical HTML and JavaScript examples to demonstrate event handling step by step. Learners can explore different approaches, compare event-handler methods, and understand how JavaScript responds to user interactions.

The HTML file contains the main learning notes and examples, while the separate JavaScript file demonstrates event-handler functions used in the DOM event exercises.

**Note:** Some examples in the HTML notes are marked for rechecking or contain incomplete sections, particularly the delete-confirmation example and the topics on event bubbling and event delegation. These are presented as learning notes and exercises rather than verified, fully working implementations.
